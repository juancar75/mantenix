# Registro de decisiones

Cada decisión de diseño importante se documenta en un fichero numerado: contexto, decisión, alternativas y consecuencias. No se borran: si una decisión cambia, se añade otra que la sustituye y se marca la antigua como «sustituida por NNNN».

Plantilla:

```
# NNNN. Título
- Estado: propuesta | aceptada | sustituida por NNNN
- Fecha: AAAA-MM-DD

## Contexto
## Decisión
## Consecuencias
```
